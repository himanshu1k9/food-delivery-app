# 🍕 Food Delivery Web Application

A modern, full-stack, responsive food delivery web application built to provide users with a seamless food ordering experience—from exploring curated menus to placing real-time orders.

🔗 **Live Demo:** [food-delivery-app-roan-nu.vercel.app](https://food-delivery-app-roan-nu.vercel.app/)

## 📌 Features

### 👤 User Experience
* **Interactive Menu Catalog:** Browse an extensive list of food items categorized with high-quality visual imagery, detailed descriptions, and dynamic pricing.
* **Smart Search & Filtering:** Quickly filter meals by categories or search by dish name.
* **Dynamic Cart Management:** Add, update, or remove items in real time with instant order summary recalculation.
* **Responsive Layout:** Optimized for desktop, tablet, and mobile browsers using fluid UI principles.

### ⚙️ Engine & Logic
* **State Management:** Seamless synchronization of shopping cart state across session reloads.
* **Real-time Input Validation:** Built-in form and checkout verification for delivery addresses and payment inputs.
* **Optimized Image Loading:** CDN-hosted images with graceful fallback strategies for fast performance.

## 🚀 Getting Started

Follow these instructions to set up and run the project locally on your machine.

### Prerequisites
Make sure you have Node.js and npm/yarn installed on your machine:
* **Node.js:** `>=18.0.0`
* **npm:** `>=9.0.0`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/food-delivery-app.git
   cd food-delivery-app

  npm install
  npm run dev
  Navigate to http://localhost:5173 (or the URL displayed in your terminal).
